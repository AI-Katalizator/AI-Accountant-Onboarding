# docreader 0.2.0

Сервис чтения первичных документов для сценариев n8n (AI-Accountant-1C). Без облака, без PyMuPDF.

## Как читает
1. PDF с текстовым слоем → **pdfplumber**: слова с координатами.
   * УПД / счёт-фактура / ТОРГ-12: строка номеров граф («А Б 1 1а … 9», «1 2 … 15») задаёт графы;
     границы — по линиям сетки, без сетки — лучший из двух вариантов (середины / левые края номеров граф).
     Строки — по номеру строки в графе «А» и линиям сетки; перенос строки на следующую страницу приклеивается.
   * Акт: таблица по заголовкам («Наименование», «Кол-во», «Цена», «Сумма»), итоги и НДС — из текста под таблицей.
   * Шапка — regex по тексту (номер, дата, статус, стороны, ИНН/КПП, платёжки, основание, договор).
2. PDF без текстового слоя → **pypdfium2** рисует страницы → **Ollama qwen2.5vl:7b-16k**:
   шаг 1 — вид документа (картинка 90 dpi), шаг 2 — prompt.md определения + общие правила + JSON-схема
   определения (structured output). Ответ проверяется pydantic-схемой определения.
3. Тип документа: заголовок («Акт …», «Договор …», «Доверенность …», УПД, ТОРГ-12) + маркеры из classifier_rules.json.
4. Жёсткие проверки (`checks[]`): контрольная цифра ИНН, формат КПП, кол-во × цена = сумма,
   ставка × сумма = НДС, сумма строк = «Всего к оплате», без НДС + НДС = с НДС, «без НДС» ≠ 0%,
   номер договора ≠ номер платёжки, обязательные реквизиты.

## API
* `GET /health` → версия, доступность Ollama и модели.
* `POST /read` `{"path": "/путь/как/в/n8n.pdf", "vision": "auto|never|always", "include_text": true}` →
  карточка в полях v003: doc_type, upd_status, doc_number, doc_date, seller_*, buyer_*, contract_*, payment_docs,
  total_without_vat, total_vat, total_with_vat, vat_mode, vat_rate, lines[] (line_no, name, unit, qty, price,
  sum_without_vat, vat_rate, vat_sum, sum_with_vat), lines_sum, check_lines_sum, checks[], checks_ok, warnings[],
  warnings_ocr[], source (`text_layer` | `vision` | `none`), doc_text, doc_type_id.

## Запуск
* У клиента: `docker compose up -d docreader` (Dockerfile, нужен интернет один раз).
* Офлайн-сборка (`Dockerfile.offline`, `wheels/`) и тесты (`tests/`) в клиентскую поставку не входят.
