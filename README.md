# AI-Katalizator Onboarding

**Онбординг среды ИИ-бухгалтера для 1С.** Пакет, с которым ИИ-агент (Cursor, Codex и т. п.) вместе с вами разворачивает рабочую среду в контуре вашей компании: n8n, распознавание документов (docreader), локальная модель Ollama, проверка подключения к 1С и профиль организации.

> Секретов в репозитории нет. Пароли и ключи вы вводите сами — в Credentials n8n и в скрытые поля проверок.

## Что это и для кого

- **Для бухгалтерий и владельцев бизнеса**, купивших сценарии AI-Katalizator, — чтобы подготовить среду без ручной настройки.
- **Для IT-специалиста клиента** — чтобы прозрачно видеть, что ставится, куда и с какими доступами. «Чёрного ящика» нет: см. [технические требования](docs/TECHNICAL_REQUIREMENTS.md).

Среда ставится **в вашем контуре**: ПК, сервер компании или доверенная ВМ, где уже работают базы 1С. Данные документов в наше облако не уходят.

## Что НЕ входит

- **Сценарии учёта** (поступление актов/УПД, Банк-Касса и т. д.) — поставляются отдельно, после покупки; подключаются импортом в уже установленный n8n.
- **MCP для 1С** — запланирован позже.
- **Хостинг** — не предоставляем; всё работает на ваших машинах.
- Изменение конфигурации 1С — не делаем; сценарии создают только непроведённые черновики.

## Быстрый старт

1. Скачайте пакет: `git clone https://github.com/AI-Katalizator/AI-Accountant-Onboarding.git` или архив (GitHub «Download ZIP» либо ссылка на облачный диск, полученная при покупке).
2. Откройте папку в ИИ-агенте (например, Cursor).
3. Скажите агенту: **«Установи по SKILL.md»**.
4. Агент проверит машину, предложит установить недостающее, поможет настроить публикацию 1С (OData) и соберёт `profile.json`. Вы подтверждаете шаги и сами вводите пароли.

Не хотите ставить сами — возможна установка «под ключ» через удалённый доступ к вашему контуру (условия — у владельца продукта).

## Обновления

1. `git pull` (или скачайте новый архив) и прочитайте [CHANGELOG.md](CHANGELOG.md).
2. Если изменились `docker/` или ноды — попросите агента пересобрать: `docker compose -f docker/docker-compose.yml up -d --build`.
3. Тома данных (`N8N_DATA_DIR`, папки документов) **не удаляются и не пересоздаются**: сценарии, credentials и документы сохраняются. Обновления делаем обратно совместимыми.
