# AI-Katalizator Onboarding

## Сначала про продукт (для бухгалтера)

**AI-Katalizator** делает готовые сценарии для 1С:Бухгалтерии предприятия.  
Вы кладёте входящий документ (акт, УПД и т. п.) — сценарий готовит в 1С **задачу** и **непроведённый черновик** документа. Проверяете и проводите вы — как привыкли, внутри 1С. Конфигурацию 1С мы не меняем.

Работает **у вас**: на компьютере компании, сервере или уже своей ВМ. Документы и базы в наше облако не уходят.  
Сценарии **покупаются отдельно** (по типу документов). Этот репозиторий — не сами сценарии.

---

## Что лежит в этом репозитории

Здесь — **разворачивание инфраструктуры**: то, без чего сценарии не запустятся.

Простыми словами, пакет помогает поставить «кухню»:
- программу-оркестратор **n8n** (в Docker),
- чтение/распознавание PDF (docreader),
- локальную модель для сканов (Ollama),
- проверку связи с вашей 1С,
- файл настроек организации (`profile.json`).

Дальше в эту же среду подключаются уже купленные сценарии — отдельным шагом, без новой «кухни» под каждый сценарий.

Если вы бухгалтер и хотите «чтобы просто заработало» — откройте папку в Cursor (или другом ИИ-ассистенте) и скажите: **«Установи по SKILL.md»**. Ассистент ведёт по шагам; каждое действие — только после вашего «да». Пароли и ключи вводите вы сами, в защищённые поля.

Не хотите заниматься установкой — напишите нам: возможна установка под ключ по удалённому доступу к **вашему** контуру (не наш хостинг).

IT-специалисту: подробные требования — в [docs/TECHNICAL_REQUIREMENTS.md](docs/TECHNICAL_REQUIREMENTS.md).

## Что здесь есть / чего нет

| Есть | Нет |
|---|---|
| Установка среды по `SKILL.md` | Сценарии учёта (акты, УПД, банк…) — **покупаются отдельно** |
| Профиль организации на диске | Изменение конфигурации 1С |
| Инструкции по публикации 1С (OData) | Наш хостинг / облако с вашими базами |
| Самопроверка «всё поднялось» | Обещание «проведёт любой документ без вас» |

## Как начать (коротко)

1. Скачайте репозиторий: [Download ZIP](https://github.com/AI-Katalizator/AI-Accountant-Onboarding/archive/refs/heads/main.zip) или  
   `git clone https://github.com/AI-Katalizator/AI-Accountant-Onboarding.git`
2. Откройте папку в Cursor (или другом ассистенте).
3. Скажите: **«Установи по SKILL.md»**.
4. Когда среда и профиль готовы — подключаете купленный сценарий (отдельная поставка). Ассистент импортирует его в уже работающий n8n.

Подробный путь клиента (технический черновик для упаковки): [docs/jtbd_put_klienta_tehnicheskij.md](docs/jtbd_put_klienta_tehnicheskij.md).

## Обновления

`git pull` или новый ZIP → при необходимости попросите ассистента обновить контейнеры. Ваши данные n8n и папки документов не стираем.
