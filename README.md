# AI-Katalizator Onboarding

Публичный пакет **разворота рабочей среды** для помощника AI-Katalizator.  
Сценарии учёта сюда не входят — они подключаются отдельно после покупки.

---

## Что такое AI-Katalizator

AI-Katalizator — это готовые сценарии обработки входящей первички в 1С. Конфигурацию менять не нужно: помощник работает поверх типовой 1С:Бухгалтерия предприятия.

**Готовый сценарий** — это зафиксированный маршрут: одни и те же прописанные шаги от входящего файла до черновика в 1С. Помощник не импровизирует и не «придумывает» проводки. Он идёт по заранее описанному порядку: проверить стороны и реквизиты, определить учёт по правилам или прецедентам, создать непроведённый черновик и оставить его в задаче. Проводит документ всегда бухгалтер.

Документ попадает в общую папку и сразу становится задачей в 1С. Разбор идёт в контуре компании — на вашем компьютере, сервере фирмы или уже доверенной инфраструктуре, куда вы сами выносите базы. Данные не уходят в чужой облачный сервис продукта.

Так устроена защита от нейрогаллюцинаций в учёте: нет свободного ответа модели «куда провести», есть жёсткий маршрут и непроведённый черновик, который ждёт проверки. Если чего-то не хватает или есть сомнение — причина пишется в задачу, а не маскируется красивой проводкой.

Линейка сценариев — под разные типы первички: акты, УПД, счета-фактуры, банковские выписки, договоры. Сценарий покупается единовременно, без абонентской платы, с подключением на организацию. Бухгалтер остаётся в привычном интерфейсе 1С; задача делает работу помощника прозрачной.

## Зачем этот репозиторий

Этот репозиторий — онбординг: разворот среды и подготовка контура под сценарии AI-Katalizator. Сами сценарии обработки документов покупаются отдельно.

Путь клиента простой. Сначала поднимаем рабочую среду в вашем контуре и готовим 1С (публикация базы и доступ для помощника). Затем заполняем профиль компании и проходим онбординг правил учёта по договорам. После этого подключаем купленные сценарии — и документы уже идут по зафиксированным правилам.

Итог онбординга: инфраструктура готова, правила понятны, сценарии можно подключать без повторной установки «с нуля».

Подробный технический разбор шагов: [docs/jtbd_put_klienta_tehnicheskij.md](docs/jtbd_put_klienta_tehnicheskij.md).  
Клиентская памятка «что покупаете»: [docs/put_klienta.md](docs/put_klienta.md).

## Как начать установку среды

1. Скачайте пакет: [Download ZIP](https://github.com/AI-Katalizator/AI-Accountant-Onboarding/archive/refs/heads/main.zip) или  
   `git clone https://github.com/AI-Katalizator/AI-Accountant-Onboarding.git`
2. Откройте папку в Cursor (или другом ИИ-ассистенте установки).
3. Скажите: **«Установи по SKILL.md»**.
4. Подтверждайте шаги; секреты вводите сами в защищённые поля.

Не хотите ставить сами — возможна установка под ключ по удалённому доступу к **вашему** контуру (условия — у владельца продукта).

IT-специалисту: [технические требования](docs/TECHNICAL_REQUIREMENTS.md).
