# AI-Katalizator Onboarding

Публичный пакет **разворота рабочей среды** для помощника AI-Katalizator.  
Сценарии учёта сюда не входят — они подключаются отдельно после покупки.

---

## Что такое AI-Katalizator

**AI-Katalizator** — готовые сценарии обработки **входящей первичной документации** для 1С:Бухгалтерия предприятия.

Помощник снимает с бухгалтера рутину «набить документ с нуля»: разбирает входящий файл, сверяет стороны и реквизиты, определяет, как отразить операцию в учёте, и готовит в 1С **задачу** и **непроведённый черновик**. Бухгалтер остаётся в привычном интерфейсе 1С: проверяет и проводит сам. Конфигурацию 1С мы **не меняем**.

Линейка сценариев — по типам документов и операциям, без абонентской платы за «подписку на всё сразу». В работе и в планах поставки:

- акты и УПД (услуги и товары);
- счета-фактуры от поставщиков;
- выписки банка;
- счета от поставщиков;
- заведение и сопровождение договоров;
- дальнейшие типы первички — по мере выпуска.

Всё работает **у вас, в контуре компании**: на компьютере, на сервере фирмы или на уже доверенной ВМ / в облаке, куда вы сами выносите базы. Документы и данные не уходят в чужой контур продукта. Покупка сценария — **единовременно**; обновления при смене конфигурации 1С согласуются отдельно.

Мы не обещаем «волшебство без проверки»: спорное помощник фиксирует в задаче, черновик всегда ждёт бухгалтера.

## Зачем этот репозиторий

Чтобы сценарии заработали, один раз нужна **рабочая среда** и понятный старт. Этот репозиторий — как раз онбординг инфраструктуры: помощник по установке ведёт вас по шагам (только с вашего «да»), готовит контур под сценарии и собирает профиль организации.

Сам сценарий учёта вы получаете **отдельно** (покупка / доступ) и подключаете уже в готовую среду — без новой «установки с нуля» под каждый тип документа.

### Как выглядит путь клиента (кратко)

1. **Доступ** — покупка сценария и ссылка на этот пакет среды.  
2. **Среда** — установка по `SKILL.md` вместе с помощником.  
3. **1С** — публикация базы и пользователь для помощника (часто делает администратор 1С).  
4. **Профиль компании** — ответы на вопросы; пароли и ключи вводите только вы.  
5. **Онбординг учёта** — разовое наполнение правил по договорам из уже проведённых документов (расчёты с поставщиками).  
6. **Подключение сценария** — импорт купленного сценария в готовую среду.  
7. **Пробный документ** — задача + непроведённый черновик → вы проверяете и проводите.  
8. **Обычная работа** — тот же путь; исключения — в задаче простым языком.

Подробный технический разбор шагов: [docs/jtbd_put_klienta_tehnicheskij.md](docs/jtbd_put_klienta_tehnicheskij.md).  
Клиентская памятка «что покупаете»: [docs/put_klienta.md](docs/put_klienta.md).

## Как начать установку среды

1. Скачайте пакет: [Download ZIP](https://github.com/AI-Katalizator/AI-Accountant-Onboarding/archive/refs/heads/main.zip) или  
   `git clone https://github.com/AI-Katalizator/AI-Accountant-Onboarding.git`
2. Откройте папку в Cursor (или другом ИИ-ассистенте установки).
3. Скажите: **«Установи по SKILL.md»**.
4. Подтверждайте шаги; секреты вводите сами в защищённые поля.

Не хотите ставить сами — возможна установка под ключ по удалённому доступу к **вашему** контуру (условия — у владельца продукта).

IT-специалисту: [технические требования](docs/TECHNICAL_REQUIREMENTS.md).

## Что в пакете / чего нет

| Есть | Нет |
|---|---|
| Установка среды по `SKILL.md` | Готовые сценарии учёта (покупаются отдельно) |

| Инструкции по публикации 1С | Наш хостинг ваших баз |

## Обновления

Скачайте новую версию или сделайте `git pull`, смотрите [CHANGELOG.md](CHANGELOG.md). При изменении среды попросите ассистента обновить контейнеры. Ваши данные и папки документов не стираем.
