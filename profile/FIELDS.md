# Поля профиля: что это и откуда берётся

Профиль — это несекретные сведения об организации. Все сценарии берут данные отсюда.
Паролей, логинов и ключей в профиле нет. Они вводятся только в n8n → Credentials.

| Поле | Что это | Как узнаём |
|---|---|---|
| organization.name_full / name_display | Полное и короткое название | Спрашиваем; сверяем с 1С |
| organization.name_in_1c | Как организация названа в 1С | Находим через OData |
| organization.aliases | Другие написания названия (в документах) | Предлагаем сами, клиент поправляет |
| organization.inn / kpp / ogrn | Реквизиты | Спрашиваем; ИНН проверяем по контрольной цифре |
| organization.ref_guid | Ссылка на организацию в 1С | Находим через OData по ИНН |
| onec.database_name / database_status | Имя базы; рабочая или копия | Спрашиваем. Первый запуск — только на копии |
| onec.web_publication_url_host | Адрес публикации, как он открывается в браузере | Спрашиваем (например http://localhost:8081/base) |
| onec.web_publication_url_n8n / odata_base_url | То же, но изнутри Docker | Вычисляем: localhost → host.docker.internal; + /odata/standard.odata |
| onec.http_credential_name | Название записи с логином AI в n8n | Предлагаем «1С — AI» |
| onec.mcp_base_url / mcp_channel | Для MCP 1С (на будущее, банк-касса) | Необязательно, по умолчанию пусто |
| onec.nomenclature_placeholder | Номенклатура-заглушка «Оплата по счёту» | Находим через OData, иначе просим создать |
| folders.*_host / *_n8n | Одна и та же папка: путь на компьютере и путь внутри n8n | Скилл создаёт папки сам; *_n8n вычисляется |
| task_settings.default_executor | Кому ставятся задачи по умолчанию | Выбор из пользователей 1С (OData) |
| task_settings.human_executors.purchases | Исполнитель по закупкам | Выбор из пользователей 1С |
| task_settings.due_days | Срок задачи в днях | Спрашиваем, по умолчанию 3 |
| file_storage.* | Режим хранения файлов 1С: **только тома на диске** (не в базе) | Спрашиваем; путь тома обязателен |
| folders.file_volume_host / file_volume_n8n | Каталог тома 1С на диске и путь изнутри n8n | Уже есть — берём путь клиента; нет — создаём рядом с папками документов и просим прописать в 1С |
| execution.timezone | Часовой пояс | Берём с компьютера, подтверждаем |
