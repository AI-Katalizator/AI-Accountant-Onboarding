# AI-Accountant-1C — пакет установки у клиента

Для ИИ-агента (Cursor, Codex и т. п.): откройте `SKILL.md` и следуйте ему.
Для человека: скажите ассистенту «Установи ИИ-бухгалтера» — он сам всё проверит, спросит и установит вместе с вами.

Установка среды входит в то, что получает клиент: этот пакет — инструкция для ИИ-агента, который ставит всё вместе с клиентом. Разбираться в настройке самому не нужно.
Среда ставится в контуре компании: на свой ПК, на сервер фирмы или на уже доверенную виртуальную машину/облако, где компания держит базы 1С. Данные остаются в этом контуре, в наше облако ничего не уходит. Хостинг мы не предоставляем.

Состав:
- `SKILL.md` — сценарий установки диалогом;
- `helpers/` — осмотр машины в контуре клиента (Mac/Windows), проверка 1С через OData, проверка профиля, самопроверка;
- `docker/` — n8n 2.39.5 в Docker (с @e965/xlsx — нужна только для разбора состава реквизитов первичных документов, не для банк-клиента) и docreader 0.2.0 в Docker; Ollama ставится без Docker;
- `ollama/` — настройка модели для сканов;
- `profile/` — шаблон профиля и описание полей;
- `docs/` — инструкции: DaData, настройка 1С, установка программ.

В пакете нет паролей и ключей.

Порядок: сначала среда и профиль компании, затем следующим шагом — купленный сценарий (он подхватывает готовый профиль). Сценарии не импортируются во время установки среды.
Сценарии создают в 1С только непроведённые черновики и не меняют конфигурацию 1С. MCP пока не ставим.
Профиль: этот пакет только сохраняет `profile.json` на диск клиента; перенос профиля в workflow «Профиль Организации» в n8n делает установщик купленного сценария (следующий контур).
Поддержка: если установка не идёт, ассистент установки описывает проблему простыми словами и передаёт её владельцу продукта AI-Katalizator (Виктория); канал связи сообщается клиенту при покупке.
