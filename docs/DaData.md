# Ключ DaData — 5 минут

DaData подсказывает реквизиты контрагентов по ИНН. Нужен для сценариев, где появляется новый контрагент.

1. Откройте https://dadata.ru и нажмите «Регистрация». Подойдёт рабочая почта.
2. Подтвердите почту, войдите в личный кабинет.
3. В разделе «API-ключи» (Профиль → API) вы увидите **API-ключ** и **Секретный ключ**.
4. Откройте n8n (http://localhost:5678) → слева «Credentials» → «Create».
5. Выберите тип, который назовёт ассистент установки, и вставьте оба ключа. Название — «DaData».
6. Нажмите «Save».

Ключи никому не пересылайте, в том числе ассистенту в чат. Если ключ попал в чужие руки —
в личном кабинете DaData нажмите «Сменить ключ» и вставьте новый в n8n.

Бесплатного тарифа обычно хватает на работу одной организации (это наша оценка — при больших
объёмах DaData предложит платный тариф).
