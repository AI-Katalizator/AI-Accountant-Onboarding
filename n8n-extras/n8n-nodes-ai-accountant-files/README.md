# AI Accountant: безопасные файловые операции n8n

Локальная визуальная нода для операций, которых нет в стандартной поставке n8n.

## `AI Accountant: Переместить файл`

Нода принимает исходный и целевой путь и переносит один файл. Оба пути должны
находиться внутри `/home/node/.n8n-files` (или внутри каталога из переменной
`AI_ACCOUNTANT_FILES_ROOT`). Перезапись существующего файла запрещена.

Нода нужна сценарию `1.1_Центр обработки документов`, потому что стандартная
нода `Read/Write Files from Disk` в n8n 2.18.5 умеет читать и записывать файлы,
но не умеет переносить их с удалением источника. Глобально небезопасная нода
`Execute Command` для этого не включается.
